🔷 Étape 1: Configuration de HttpClient

// app.config.ts
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient() // Active HttpClient dans l'application
  ]
};

🔑 Mots-clés détaillés:

  • provideHttpClient(): Fonction qui configure et active le module HttpClient dans toute l'application. Sans cet appel dans app.config.ts, vous ne pourrez pas utiliser HttpClient dans vos services. C'est l'équivalent moderne de l'ancien HttpClientModule dans les applications standalone.

🔑 Pourquoi inject() ?

  • Plus propre: Évite d'avoir un constructeur encombré de paramètres.
  • Type-safe: TypeScript infère automatiquement le type du service injecté.
  • Fonctionnel: Utilisable en dehors des classes (dans des fonctions, guards, resolvers).
  • Standard: C'est la méthode recommandée depuis Angular 14+.

🚀 Étape 3: Gestion d'État avec Signals

Angular 16+ introduit les Signals, une nouvelle façon de gérer l'état réactif. C'est le cœur de cet exercice.

// football.component.ts
import { Component, inject, signal } from '@angular/core';

export class FootballComponent {
  // 1. Déclaration (Lecture seule pour l'extérieur)
  readonly standings = signal<TeamStanding[]>([]);
  readonly loading = signal(false);
  
  // 2. Mise à jour avec .set()
  updateData(newData: TeamStanding[]) {
    this.standings.set(newData); // Remplace la valeur
  }
  
  // 3. Mise à jour avec .update()
  toggleLoading() {
    this.loading.update(v => !v); // Basé sur la valeur précédente
  }
}

🔑 Concepts Signals Détaillés:

📡 signal(initialValue)

Crée un conteneur réactif ("wrapper") autour d'une valeur. Angular sait exactement où ce signal est utilisé et ne met à jour QUE les parties de l'interface qui en ont besoin.

Exemple: count = signal(0)

✍️ .set(newValue)

Remplace complètement la valeur du signal. Utilisez-le quand la nouvelle valeur ne dépend pas de l'ancienne (ex: charger des données API).

Exemple: this.standings.set(apiData)

🔄 .update(fn)

Met à jour la valeur en se basant sur la valeur actuelle. Idéal pour incrémenter, ajouter à une liste, ou basculer un booléen.

Exemple: this.count.update(n => n + 1)

👀 value() (Lecture)

Pour lire la valeur d'un signal (dans le code ou le template), on l'appelle comme une fonction. Cela crée une dépendance réactive.

Exemple: console.log(this.count()) ou {{ count() }}

🔷 Étape 4: Utilisation dans le Template

<!-- Template avec Signals et Control Flow -->

<!-- Lecture du signal avec les parenthèses () -->
@if (loading()) {
  <div class="loader">Chargement...</div>
}

@if (error()) {
  <div class="error">{{ error() }}</div>
}

<!-- Utilisation directe du signal dans la boucle -->
@for (team of standings(); track team.id) {
  <div class="team-row">
    <span>{{ team.position }}</span>
    <span>{{ team.name }}</span>
  </div>
}

🔑 Points Clés:

  • loading(): Les parenthèses sont obligatoires pour lire la valeur. Si vous oubliez les (), vous affichez l'objet Signal lui-même !
  • Fine-Grained Reactivity: Quand loading change, Angular met à jour uniquement ce bloc @if, sans re-vérifier tout l'arbre de composants. C'est beaucoup plus performant que l'ancien système (Zone.js).

🔷 Étape 5: Connecter RxJS (Service) et Signals (Component)

C'est le pattern le plus courant aujourd'hui : utiliser RxJS pour les événements asynchrones (HTTP) et Signals pour l'état synchrone (Vue).

loadData() {
  this.loading.set(true); // 1. Signal: UI affiche loader
  
  // 2. RxJS: Appel HTTP
  this.service.getStandings().subscribe({
    next: (data) => {
      // 3. Signal: Mise à jour des données
      this.standings.set(data);
      this.loading.set(false);
    },
    error: (err) => {
      this.error.set(err.message);
      this.loading.set(false);
    }
  });
}

📋 Résumé: RxJS vs Signals

Caractéristique RxJS (Observables) Signals
Utilisation principale Événements asynchrones (HTTP, Timers) Gestion d'état synchrone (UI State)
Valeur Flux de valeurs dans le temps Détient toujours une valeur courante
Accès Nécessite subscribe() Accès direct via value()
Dans ce projet Utilisé dans le Service Utilisé dans le Component
